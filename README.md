# เส้นทางเล็ก มหาขุนเขา — ต้นแบบเรียลไทม์

เกมแข่งรถล้อเปิดบนภูเขาสำหรับ 2–8 คน เซิร์ฟเวอร์เป็นผู้ตัดสินความเร็ว ตำแหน่ง การเปลี่ยนเลน อุบัติเหตุ และผู้ชนะ ข้อมูลห้องอยู่ในหน่วยความจำ

## เริ่มเล่น

ต้องมี Node.js 20.19+ หรือ 22.12+ (ทดสอบด้วย Node 24)

```sh
npm install
npm run dev
```

เปิด http://localhost:5173 สร้างห้อง แล้วชวนเพื่อนด้วยรหัสห้อง หรือกด **เพิ่มบอท** เพื่อทดลองคนเดียว ผู้เล่นทุกคนกดพร้อมก่อนเจ้าของห้องกดเริ่ม แข่งได้ 2–8 คันรวมบอท การเชื่อมต่อจากเครื่องอื่นต้องเข้าถึง URL เครือข่ายที่ Vite แสดงได้ หยุดเซิร์ฟเวอร์ด้วย Ctrl+C; ห้องจะหายเมื่อเซิร์ฟเวอร์หยุด

```sh
npm run build
npm test
```

## วิธีเล่น

- สนามยาว 7,000 เมตร จากตีนเขาขึ้นบริเวณยอดและลงอีกฝั่ง สุ่มจาก seed มีโค้งกว้าง โค้งแคบ โค้งยาว และทางตรงยาว
- แตะ **เร่ง / รักษา / เบรก** ได้ทันที คำสั่งมีผลต่อเนื่องจนแตะปุ่มอื่น ไม่มีช่วงนับถอยหลัง ความเร็วบนหน้าจอเป็นกิโลเมตรต่อชั่วโมง
- เลือกเลนซ้ายหรือขวาได้ รถค่อย ๆ ย้ายเลนเมื่อช่องว่างปลอดภัย หลายคันใช้เลนเดียวกันได้หากมีระยะห่างพอ รถที่ติดคันหน้าจะชะลอ
- ความเร็วเกินในโค้งทำให้เสียความเร็ว การฝืนรุนแรงที่โค้งหน้าผามีโอกาสเสียชีวิตเฉพาะเมื่อผู้เล่นกดยืนยันโค้งนั้น ถ้าไม่ยืนยันระบบชะลอให้ปลอดภัย ไม่มีแต้มสภาพรถ
- บอทเลือกคำสั่งและเลนโดยเซิร์ฟเวอร์ และไม่ยืนยันความเสี่ยงเสียชีวิต กล้องคนขับจำกัดมุมแนวนอนไม่เกิน 90 องศา ระยะมองเห็นประมาณจากถนนและภูมิประเทศขณะเคลื่อนที่
- หากหลุด ระบบคงความเร็วและยกเลิกการยืนยันความเสี่ยง สามารถกลับเข้าด้วย session token ของเบราว์เซอร์ และผู้เข้าหลังเริ่มเป็นผู้ชม

## ข้อจำกัดของต้นแบบ

- สนามสร้างจากแพตเทิร์นโค้งที่มีการสุ่มรายละเอียด เส้นทางกติกาและถนน 3D ใช้เส้นทางเดียวกัน แต่ยังไม่ใช่ generator ภูเขาทุกชนิด ตัวตรวจสนามยังไม่ครอบคลุมทุกเงื่อนไข
- ฉากและรถเป็น low-poly สเกลภาพยังเป็นภาพแทนเพื่อให้เห็นรถง่าย ไม่ใช่แบบจำลองรถและภูมิประเทศที่มีสัดส่วนทางกายภาพแม่นยำ
- บอทใช้กฎง่าย ๆ ไม่ใช่ AI ที่ปรับระดับความสามารถ ระบบมองเห็นประมาณจากแนวถนนและพื้นผิวภูเขา ยังไม่ได้จำลองการบังสายตาของทุกวัตถุ
- ยังไม่มีฐานข้อมูล บัญชี โฮสติ้งสาธารณะ สถิติสมดุล หรือการทดสอบมือถือและเครือข่ายจริงอย่างครบถ้วน เวลาแข่งยังต้องวัดจากผู้เล่นจริง
- ยังควรตรวจความปลอดภัยของเซิร์ฟเวอร์และการจำกัดทรัพยากรก่อนเปิดเป็นบริการสาธารณะ

## Deploy บน Render

สร้าง Web Service จาก GitHub repository ของโปรเจกต์ โดยใช้ Node.js 22 หรือใหม่กว่า ตั้ง Build Command เป็น `npm ci --include=dev && npm run build` และ Start Command เป็น `npm start` เซิร์ฟเวอร์อ่านพอร์ตจาก `PORT` และให้บริการหน้าเว็บกับ Socket.IO ผ่านพอร์ตเดียวกัน ใช้หนึ่ง instance เพราะห้องอยู่ในหน่วยความจำและจะหายเมื่อ instance รีสตาร์ตหรือ deploy ใหม่

## รูปแบบแข่งและเรียนรู้

เลือกโหมดสั้น 3.5 กม. หรือยาว 7 กม. ตอนสร้างห้อง โหมดสั้นตั้งเป้าประมาณ 2–3 นาที (บอทจำลองสาม seed จบประมาณ 137–140 วินาที) เลนด้านในของโค้งใช้ระยะสั้นกว่าแต่จำกัดความเร็วต่ำกว่า เลนนอกใช้ระยะมากกว่าแต่ผ่านได้เร็วขึ้น เป็นกติกาเกมแบบประมาณ ยังไม่ใช่การจำลองไลน์ขับทางกายภาพเต็มรูปแบบ กดเปิดเสียงบนแถบแข่งเพื่อเปิดเสียงสังเคราะห์ตามความเร็วและเหตุการณ์ ผลหลังแข่งแสดงสถิติโค้งและแซง เจ้าของห้องกดแก้มือกลับ lobby สนามเดิมได้ ทุกคนกดพร้อมใหม่และเปลี่ยนรถได้

## หน่วยความเร็วและสเกลภาพ

เส้นทาง 3D ถูกปรับให้หนึ่งหน่วยฉากเท่ากับหนึ่งเมตรตามแนวถนน โหมดสั้นและยาวใช้เวลาเดินจริง (pace=1) มาตรวัดแสดงระยะที่เคลื่อนจริงต่อเวลาจริงหลังรวมผลยางไถล เลน และการติดรถ ไม่ใช่เพียงค่าความเร็วสะสมในเครื่องยนต์ ทางราบที่ 100 กม./ชม. เคลื่อน 27.78 ม./วินาที โหมดสั้น 3.5 กม. จึงใช้เวลานานกว่าเวอร์ชันเร่งเวลาเดิม ประมาณ 3–4 นาทีขึ้นกับการขับ

## ทดสอบขับเองด้วยคีย์บอร์ด

กด W ค้างเพื่อเร่ง S ค้างเพื่อเบรก ปล่อย W/S เพื่อรักษาความเร็ว A/D เปลี่ยนทีละเลน (ไม่ใช่พวงมาลัยอิสระ) ขณะพิมพ์ใน input จะไม่สั่งขับ สลับหน้าต่างจะปล่อยคำสั่งที่กดค้าง มุมคนขับเริ่มตามทิศรถ กดเมาส์ซ้ายลากหันมองแล้วปล่อยเพื่อคืนทิศหน้า โค้งไม่มีการลด grip ก่อนถึงขีดจำกัด และแก้ต้นทุนเลนนอกที่เคยทบซ้ำจนรถช้าลงทุก tick

## การเลี้ยวอิสระ

A/D ค้างเพื่อขยับแนวรถต่อเนื่องภายในขอบถนน ปล่อยแล้วหยุดเลี้ยวอยู่ ณ ตำแหน่งนั้น ไม่ดึงกลับเข้ากลางเลน รองรับปุ่มเลี้ยวค้างบนจอเช่นกัน เซิร์ฟเวอร์ตรวจระยะห่างขณะเลี้ยว กล้อง First Person มีกรอบกระจกหน้า กระจกด้านซ้ายและขวาแยกข้าง และกล้องมองหลังตรงกลางบน ภาพเป็นกล้องด้านหลังจริง แต่ยังไม่ได้จำลองความโค้งและการสะท้อนทางแสงของกระจกจริง

## ถนนจริง 1081

เลือกสนาม 10, 20, 30 หรือ 39.9 กม. ตอนสร้างห้อง เส้นทางจากสามแยกอวนไปทางบ่อเกลือใช้ OpenStreetMap ผ่าน FOSSGIS/OSRM และระดับสูง SRTM 90m ไม่เรียก API ภายนอกขณะเล่น ดาวน์โหลด GeoJSON เต็มเส้นทางได้จากเครดิตหน้าจอแข่ง แหล่งข้อมูลและ ODbL อยู่ใน shared/data/LICENSE-1081.md ความสูง ผิวทาง ความกว้างถนนและสิ่งแวดล้อมยังเป็นค่าประมาณ ไม่ใช่แผนที่สำรวจสำหรับนำทาง

## วิวประกอบสนาม 1081

สนามถนนจริงมีป่าหลากสี ไหล่ทาง ราวกันตก โขดหิน หมู่บ้านเล็ก พื้นที่เกษตรขั้นบันได และป้ายระยะเกมทุก 1 กม. จัดวางซ้ำได้แน่นอนและเว้นถนนสำหรับรถ ใช้ instancing สำหรับต้นไม้ หิน และราวเพื่อลดจำนวน draw calls ฉากเหล่านี้เป็นงานตกแต่งที่สร้างขึ้น ไม่ได้อ้างอิงตำแหน่งสิ่งปลูกสร้างจริง ป้าย KM / GAME เป็นระยะในสนาม ไม่ใช่หลักกิโลเมตรทางราชการ


## สนามและกติกาล่าสุด

หน้าเลือกสนามใช้ถนน 1081 สี่ระยะ: 10, 20, 30 และ 39.9 กม. ทุกสนามเริ่มที่จุดเดียวกันและตัดจบตามระยะ สองสนามสุ่มเดิมและตัวเลือก 8 กม. ถูกถอดจากหน้าสร้างห้อง ข้อมูล OSM เต็มเส้นทางมีระยะประมาณ 39.8792 กม. ปรับเป็น 39.9 กม. ในเกม ระดับสูง SRTM และฉากตกแต่งเป็นค่าประมาณ

เลี้ยว A/D ได้ต่อเนื่องในขอบถนน ระยะกันรถในกติกา realtime เปลี่ยนเป็น 3 เมตรตามแนวยาว แซงได้ทั้งซ้ายขวา แต่ห้ามเบียดตัวถัง หากเข้าถึงท้ายคันหน้า คันหลังหยุดที่ 0 และต้องกดเร่งใหม่ คันหน้าไม่เสียความเร็ว ความเร็วขั้นต่ำ 20 ไม่บังคับหลังชนหรือเกิดใหม่

เข้าโค้งเร็วเกินต่อเนื่องจะเสียการเกาะและไถลออกด้านนอก เบรกหรือเลี้ยวต้านเพื่อแก้ได้ ถ้าหลุดขอบถนนจะแสดงการตกและพัก 1.8 วินาที แล้วกลับที่ระยะเดิมด้วยความเร็ว 0 หากมีรถขวางจุดเกิดจะรอช่องว่าง การควบคุมยังวิ่งตามแนวถนนและขยับด้านข้าง ไม่ใช่ฟิสิกส์รถอิสระเต็มรูปแบบ

## เล่นบนมือถือ

รองรับหน้าแข่งแบบกะทัดรัดทั้งแนวนอนและแนวตั้ง แนะนำแนวนอน กดค้างปุ่มเร่ง/เบรกและเลี้ยวซ้าย/ขวาได้พร้อมกันด้วยสองนิ้ว ปล่อยปุ่มแล้วรักษาความเร็วและหยุดเลี้ยว เมื่อสลับแอปหรือมี pointer cancel จะยกเลิกปุ่มที่กดค้าง อันดับเปิดจากปุ่มมุมซ้ายบน มุมกล้องเลือกแผนที่/ตามรถ/ในรถได้ ด้านภาพจำกัด pixel ratio บนอุปกรณ์ pointer แบบ coarse ไว้ 1.25

การทดสอบครั้งนี้: build และ unit tests ผ่าน แต่ยังไม่ได้ยืนยันบนโทรศัพท์จริงหรือภาพจาก browser emulation เนื่องจาก browser use ถูกปิดใน Work settings

ทดสอบบนโทรศัพท์ใน Wi-Fi เดียวกันโดยเปิด URL Network ที่ `npm run dev` แสดง (ไม่ใช่ localhost ของโทรศัพท์) หากใช้เวอร์ชัน Render ต้อง deploy การแก้ไขนี้ก่อน

## ตั้งค่ากราฟิก

กด ⚙ ภาพ ได้จากหน้าหลัก ห้องเตรียมแข่ง และระหว่างแข่ง เลือกต่ำ/กลาง/สูง มีผลทันทีและเก็บใน localStorage ของเบราว์เซอร์ โทรศัพท์เริ่มต้นที่ต่ำเมื่อยังไม่เคยเลือกเอง: pixel ratio สูงสุด 1, 1.25, 1.75 และสัดส่วนต้นไม้/หิน 30%, 60%, 100% ตามระดับ โดยตำแหน่งต้นไม้ที่เหลือยังคงเดิม ถนน รถ ราวกันตก ป้าย และกระจกทั้งสามยังอยู่ครบ เปิด–ปิดเส้นเอฟเฟกต์ความเร็วแยกได้ ตั้งค่ามีผลเฉพาะการแสดงผล ไม่เปลี่ยนกติกาหรือผลเซิร์ฟเวอร์

build ผ่าน การตรวจภาพและการวัด FPS บนโทรศัพท์จริงยังไม่ได้ทำ เนื่องจาก browser use ถูกปิดอยู่
