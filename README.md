# เส้นทางเล็ก มหาขุนเขา — ต้นแบบเรียลไทม์

เกมแข่งรถล้อเปิดบนภูเขาสำหรับ 2–8 คน เซิร์ฟเวอร์เป็นผู้ตัดสินความเร็ว ตำแหน่ง การเปลี่ยนเลน อุบัติเหตุ และผู้ชนะ ข้อมูลห้องอยู่ในหน่วยความจำ

## เริ่มเล่น

ต้องมี Node.js 20.19+ หรือ 22.12+ (ทดสอบด้วย Node 24)

```sh
npm install
npm run dev
```

เปิด http://localhost:5173 สร้างห้อง แล้วชวนเพื่อนด้วยรหัสห้อง หรือกด **เพิ่มบอท** เพื่อทดลองคนเดียว ผู้เล่นทุกคนกดพร้อมก่อนเจ้าของห้องกดเริ่ม แข่งได้ 2–8 คันรวมบอท การเชื่อมต่อจากเครื่องอื่นต้องเข้าถึง URL เครือข่ายที่ Vite แสดงได้ หยุดเซิร์ฟเวอร์ด้วย Ctrl+C; ห้องจะหายเมื่อเซิร์ฟเวอร์หยุด

```sh
npm run build
npm test
```

## วิธีเล่น

- สนามยาว 7,000 เมตร จากตีนเขาขึ้นบริเวณยอดและลงอีกฝั่ง สุ่มจาก seed มีโค้งกว้าง โค้งแคบ โค้งยาว และทางตรงยาว
- แตะ **เร่ง / รักษา / เบรก** ได้ทันที คำสั่งมีผลต่อเนื่องจนแตะปุ่มอื่น ไม่มีช่วงนับถอยหลัง ความเร็วบนหน้าจอเป็นกิโลเมตรต่อชั่วโมง
- เลือกเลนซ้ายหรือขวาได้ รถค่อย ๆ ย้ายเลนเมื่อช่องว่างปลอดภัย หลายคันใช้เลนเดียวกันได้หากมีระยะห่างพอ รถที่ติดคันหน้าจะชะลอ
- ความเร็วเกินในโค้งทำให้เสียความเร็ว การฝืนรุนแรงที่โค้งหน้าผามีโอกาสเสียชีวิตเฉพาะเมื่อผู้เล่นกดยืนยันโค้งนั้น ถ้าไม่ยืนยันระบบชะลอให้ปลอดภัย ไม่มีแต้มสภาพรถ
- บอทเลือกคำสั่งและเลนโดยเซิร์ฟเวอร์ และไม่ยืนยันความเสี่ยงเสียชีวิต กล้องคนขับจำกัดมุมแนวนอนไม่เกิน 90 องศา ระยะมองเห็นประมาณจากถนนและภูมิประเทศขณะเคลื่อนที่
- หากหลุด ระบบคงความเร็วและยกเลิกการยืนยันความเสี่ยง สามารถกลับเข้าด้วย session token ของเบราว์เซอร์ และผู้เข้าหลังเริ่มเป็นผู้ชม

## ข้อจำกัดของต้นแบบ

- สนามสร้างจากแพตเทิร์นโค้งที่มีการสุ่มรายละเอียด เส้นทางกติกาและถนน 3D ใช้เส้นทางเดียวกัน แต่ยังไม่ใช่ generator ภูเขาทุกชนิด ตัวตรวจสนามยังไม่ครอบคลุมทุกเงื่อนไข
- ฉากและรถเป็น low-poly สเกลภาพยังเป็นภาพแทนเพื่อให้เห็นรถง่าย ไม่ใช่แบบจำลองรถและภูมิประเทศที่มีสัดส่วนทางกายภาพแม่นยำ
- บอทใช้กฎง่าย ๆ ไม่ใช่ AI ที่ปรับระดับความสามารถ ระบบมองเห็นประมาณจากแนวถนนและพื้นผิวภูเขา ยังไม่ได้จำลองการบังสายตาของทุกวัตถุ
- ยังไม่มีฐานข้อมูล บัญชี โฮสติ้งสาธารณะ สถิติสมดุล หรือการทดสอบมือถือและเครือข่ายจริงอย่างครบถ้วน เวลาแข่งยังต้องวัดจากผู้เล่นจริง
- ยังควรตรวจความปลอดภัยของเซิร์ฟเวอร์และการจำกัดทรัพยากรก่อนเปิดเป็นบริการสาธารณะ

## Deploy บน Render

สร้าง Web Service จาก GitHub repository ของโปรเจกต์ โดยใช้ Node.js 22 หรือใหม่กว่า ตั้ง Build Command เป็น `npm ci --include=dev && npm run build` และ Start Command เป็น `npm start` เซิร์ฟเวอร์อ่านพอร์ตจาก `PORT` และให้บริการหน้าเว็บกับ Socket.IO ผ่านพอร์ตเดียวกัน ใช้หนึ่ง instance เพราะห้องอยู่ในหน่วยความจำและจะหายเมื่อ instance รีสตาร์ตหรือ deploy ใหม่

## รูปแบบแข่งและเรียนรู้

เลือกโหมดสั้น 3.5 กม. หรือยาว 7 กม. ตอนสร้างห้อง โหมดสั้นตั้งเป้าประมาณ 2–3 นาที (บอทจำลองสาม seed จบประมาณ 137–140 วินาที) เลนด้านในของโค้งใช้ระยะสั้นกว่าแต่จำกัดความเร็วต่ำกว่า เลนนอกใช้ระยะมากกว่าแต่ผ่านได้เร็วขึ้น เป็นกติกาเกมแบบประมาณ ยังไม่ใช่การจำลองไลน์ขับทางกายภาพเต็มรูปแบบ กดเปิดเสียงบนแถบแข่งเพื่อเปิดเสียงสังเคราะห์ตามความเร็วและเหตุการณ์ ผลหลังแข่งแสดงสถิติโค้งและแซง เจ้าของห้องกดแก้มือกลับ lobby สนามเดิมได้ ทุกคนกดพร้อมใหม่และเปลี่ยนรถได้

## หน่วยความเร็วและสเกลภาพ

เส้นทาง 3D ถูกปรับให้หนึ่งหน่วยฉากเท่ากับหนึ่งเมตรตามแนวถนน โหมดสั้นและยาวใช้เวลาเดินจริง (pace=1) มาตรวัดแสดงระยะที่เคลื่อนจริงต่อเวลาจริงหลังรวมผลยางไถล เลน และการติดรถ ไม่ใช่เพียงค่าความเร็วสะสมในเครื่องยนต์ ทางราบที่ 100 กม./ชม. เคลื่อน 27.78 ม./วินาที โหมดสั้น 3.5 กม. จึงใช้เวลานานกว่าเวอร์ชันเร่งเวลาเดิม ประมาณ 3–4 นาทีขึ้นกับการขับ

## ทดสอบขับเองด้วยคีย์บอร์ด

กด W ค้างเพื่อเร่ง S ค้างเพื่อเบรก ปล่อย W/S เพื่อรักษาความเร็ว A/D เปลี่ยนทีละเลน (ไม่ใช่พวงมาลัยอิสระ) ขณะพิมพ์ใน input จะไม่สั่งขับ สลับหน้าต่างจะปล่อยคำสั่งที่กดค้าง มุมคนขับเริ่มตามทิศรถ กดเมาส์ซ้ายลากหันมองแล้วปล่อยเพื่อคืนทิศหน้า โค้งไม่มีการลด grip ก่อนถึงขีดจำกัด และแก้ต้นทุนเลนนอกที่เคยทบซ้ำจนรถช้าลงทุก tick

## การเลี้ยวอิสระ

A/D ค้างเพื่อขยับแนวรถต่อเนื่องภายในขอบถนน ปล่อยแล้วหยุดเลี้ยวอยู่ ณ ตำแหน่งนั้น ไม่ดึงกลับเข้ากลางเลน รองรับปุ่มเลี้ยวค้างบนจอเช่นกัน เซิร์ฟเวอร์ตรวจระยะห่างขณะเลี้ยว กล้อง First Person มีกรอบกระจกหน้า กระจกด้านซ้ายและขวาแยกข้าง และกล้องมองหลังตรงกลางบน ภาพเป็นกล้องด้านหลังจริง แต่ยังไม่ได้จำลองความโค้งและการสะท้อนทางแสงของกระจกจริง

## ถนนจริง 1081

เลือกสนาม 10, 20, 30 หรือ 39.9 กม. ตอนสร้างห้อง เส้นทางจากสามแยกอวนไปทางบ่อเกลือใช้ OpenStreetMap ผ่าน FOSSGIS/OSRM และระดับสูง SRTM 90m ไม่เรียก API ภายนอกขณะเล่น ดาวน์โหลด GeoJSON เต็มเส้นทางได้จากเครดิตหน้าจอแข่ง แหล่งข้อมูลและ ODbL อยู่ใน shared/data/LICENSE-1081.md ความสูง ผิวทาง ความกว้างถนนและสิ่งแวดล้อมยังเป็นค่าประมาณ ไม่ใช่แผนที่สำรวจสำหรับนำทาง

## วิวประกอบสนาม 1081

สนามถนนจริงมีป่าหลากสี ไหล่ทาง ราวกันตก โขดหิน หมู่บ้านเล็ก พื้นที่เกษตรขั้นบันได และป้ายระยะเกมทุก 1 กม. จัดวางซ้ำได้แน่นอนและเว้นถนนสำหรับรถ ใช้ instancing สำหรับต้นไม้ หิน และราวเพื่อลดจำนวน draw calls ฉากเหล่านี้เป็นงานตกแต่งที่สร้างขึ้น ไม่ได้อ้างอิงตำแหน่งสิ่งปลูกสร้างจริง ป้าย KM / GAME เป็นระยะในสนาม ไม่ใช่หลักกิโลเมตรทางราชการ


## สนามและกติกาล่าสุด

หน้าเลือกสนามใช้ถนน 1081 สี่ระยะ: 10, 20, 30 และ 39.9 กม. ทุกสนามเริ่มที่จุดเดียวกันและตัดจบตามระยะ สองสนามสุ่มเดิมและตัวเลือก 8 กม. ถูกถอดจากหน้าสร้างห้อง ข้อมูล OSM เต็มเส้นทางมีระยะประมาณ 39.8792 กม. ปรับเป็น 39.9 กม. ในเกม ระดับสูง SRTM และฉากตกแต่งเป็นค่าประมาณ

เลี้ยว A/D ได้ต่อเนื่องในขอบถนน ระยะกันรถในกติกา realtime เปลี่ยนเป็น 3 เมตรตามแนวยาว แซงได้ทั้งซ้ายขวา แต่ห้ามเบียดตัวถัง หากเข้าถึงท้ายคันหน้า คันหลังหยุดที่ 0 และต้องกดเร่งใหม่ คันหน้าไม่เสียความเร็ว ความเร็วขั้นต่ำ 20 ไม่บังคับหลังชนหรือเกิดใหม่

เข้าโค้งเร็วเกินต่อเนื่องจะเสียการเกาะและไถลออกด้านนอก เบรกหรือเลี้ยวต้านเพื่อแก้ได้ ถ้าหลุดขอบถนนจะแสดงการตกและพัก 1.8 วินาที แล้วกลับที่ระยะเดิมด้วยความเร็ว 0 หากมีรถขวางจุดเกิดจะรอช่องว่าง การควบคุมยังวิ่งตามแนวถนนและขยับด้านข้าง ไม่ใช่ฟิสิกส์รถอิสระเต็มรูปแบบ

## เล่นบนมือถือ

รองรับหน้าแข่งแบบกะทัดรัดทั้งแนวนอนและแนวตั้ง แนะนำแนวนอน กดค้างปุ่มเร่ง/เบรกและเลี้ยวซ้าย/ขวาได้พร้อมกันด้วยสองนิ้ว ปล่อยปุ่มแล้วรักษาความเร็วและหยุดเลี้ยว เมื่อสลับแอปหรือมี pointer cancel จะยกเลิกปุ่มที่กดค้าง อันดับเปิดจากปุ่มมุมซ้ายบน มุมกล้องเลือกแผนที่/ตามรถ/ในรถได้ ด้านภาพจำกัด pixel ratio บนอุปกรณ์ pointer แบบ coarse ไว้ 1.25

การทดสอบครั้งนี้: build และ unit tests ผ่าน แต่ยังไม่ได้ยืนยันบนโทรศัพท์จริงหรือภาพจาก browser emulation เนื่องจาก browser use ถูกปิดใน Work settings

ทดสอบบนโทรศัพท์ใน Wi-Fi เดียวกันโดยเปิด URL Network ที่ `npm run dev` แสดง (ไม่ใช่ localhost ของโทรศัพท์) หากใช้เวอร์ชัน Render ต้อง deploy การแก้ไขนี้ก่อน

## ตั้งค่ากราฟิก

กด ⚙ ภาพ ได้จากหน้าหลัก ห้องเตรียมแข่ง และระหว่างแข่ง เลือกต่ำ/กลาง/สูง มีผลทันทีและเก็บใน localStorage ของเบราว์เซอร์ โทรศัพท์เริ่มต้นที่ต่ำเมื่อยังไม่เคยเลือกเอง: pixel ratio สูงสุด 1, 1.25, 1.75 และสัดส่วนต้นไม้/หิน 30%, 60%, 100% ตามระดับ โดยตำแหน่งต้นไม้ที่เหลือยังคงเดิม ถนน รถ ราวกันตก ป้าย และกระจกทั้งสามยังอยู่ครบ เปิด–ปิดเส้นเอฟเฟกต์ความเร็วแยกได้ ตั้งค่ามีผลเฉพาะการแสดงผล ไม่เปลี่ยนกติกาหรือผลเซิร์ฟเวอร์

build ผ่าน การตรวจภาพและการวัด FPS บนโทรศัพท์จริงยังไม่ได้ทำ เนื่องจาก browser use ถูกปิดอยู่

## การขับ บอท รถบ้าน และโหมดจับเวลา

- เพิ่มแถบ grip คำเตือนความเร็วเกินและอาการไถล เสียงยางสังเคราะห์เมื่อเปิดเสียงในเกม
- บอทใช้ steering ต่อเนื่อง เลือกช่องแซงจากพื้นที่จริงและความเร็วสัมพัทธ์ ถอนเบรกเมื่อไม่มีช่อง และยังมีกฎแก้ขบวนสามคันขวางทาง ระดับง่าย/กลาง/ยากใช้เพดานความเร็วต่างกัน
- เก็บสถิติดีที่สุดและรถเงาสีฟ้าใน localStorage แยกตามสนาม รถ และรุ่นกติกา รถเงาไม่มีผลต่อการชน ไม่ใช่ leaderboard ออนไลน์ ถ้าล้างข้อมูลเบราว์เซอร์ สถิติจะหาย
- จับเวลาทุก 1 กม. แสดงเวลาคุณ/เวลาของรถเงา แบ่งความคืบหน้าเป็นสี่ช่วง และแสดงระยะประมาณถึงจุดสูงสุดจากข้อมูล SRTM ของสนาม ชื่อช่วงเป็นชื่อในเกม
- เพิ่มตัวเลข FPS และตัดต้นไม้/หินที่ไกลกล้องออกเป็นระยะตามระดับกราฟิก ภาพรวมยังเห็นฉากทั้งหมด ยังไม่ได้วัด FPS/อุณหภูมิบนโทรศัพท์จริง
- รถจำลอง 10 แบบ: Honda City, Honda Civic, Toyota Yaris Ativ, Toyota Hilux Revo, Mazda 2, Suzuki Swift, Nissan Almera, Toyota Fortuner, Isuzu MU-X, Ford Ranger ใช้ geometry สร้างในเกม ไม่มีโลโก้ และไม่ได้รับรองโดยผู้ผลิต ขนาดและสมรรถนะเป็นค่าปรับเพื่อเกม รถหมุนดูตัวอย่างได้ก่อนเริ่มแข่ง

### การตรวจสอบรุ่นนี้

`npm test`: 62 ข้อผ่าน ชุดกติกาเก่า 33 ข้อถูกแยกเก็บใน shared/legacy พร้อม `npm run test:legacy` ซึ่งยังมี 15 ข้อไม่ผ่าน ไม่ได้นับเป็นผ่านหรืออ้างว่าแก้เอนจินเก่าแล้ว การจำลองบอท 8 คันต่างรุ่นวิ่งจบ 39.9 กม. ครบ และตรวจระยะตัวถังทุก tick ไม่พบซ้อนกัน Build ผ่าน การตรวจภาพรถ/UI และทดสอบสัมผัสบนโทรศัพท์จริงยังรอ เนื่องจาก browser use ถูกปิดใน Work settings

ตรวจ UI บนเบราว์เซอร์เดสก์ท็อปเพิ่มเติมแล้ว: สร้างห้อง เห็นรถทั้ง 10 ตัวเลือก/ตัวอย่างโมเดล และเริ่มแข่งคนเดียวด้วยรถบ้านพร้อม HUD ใหม่ได้ การจำลองจอมือถือผ่าน viewport capability ใช้งานไม่ได้ใน session นี้ (browser.user unavailable) จึงยังไม่ยืนยันภาพมือถือหรือประสิทธิภาพบนเครื่องจริง

## กล้องและ Racing HUD รุ่นล่าสุด

กล้อง Third Person ติดตามแนวกลางถนน มองเผื่อด้านหน้าและหันโค้งอย่างนุ่มนวล ภาพรวมวางกล้องจาก bounding sphere ของสนามจริงและสัดส่วนหน้าจอ มีเส้นทางสีทอง START/FINISH และป้ายชื่อรถ ปุ่มเต็มสนามรีเซ็ตการจัดภาพ ปุ่มติดตามรถที่เลือกจะตามตำแหน่งขณะเคลื่อนที่ โดยยังเลื่อน/ซูมรักษาระยะกล้องที่ผู้เล่นปรับไว้ได้ ลากเมาส์ซ้าย/หนึ่งนิ้วเพื่อเลื่อน ล้อเมาส์/สองนิ้วซูม คลิกขวาหมุน

HUD โทนเข้มแบบกะทัดรัด ย้ายมาตรวัดความเร็วและการขับไปมุมขวาล่าง เว้นพื้นที่กลางจอให้เห็นโค้ง ข้อความสอนรองเปิดจากรายละเอียด มุมภาพรวมเลือกคันจากอันดับเพื่อติดตามได้ ตรวจการเปิดภาพรวมเต็มสนามและติดตามรถในเบราว์เซอร์เดสก์ท็อปแล้ว

## วิวป่าริมทางรุ่นล่าสุด

เปลี่ยนพุ่มทรงเรียบเป็นพุ่มหลายกลุ่มที่มีรูปทรงไม่สมมาตร เพิ่มลำต้นและกิ่งแตกแขนง สนทรงหลายชั้น ไม้พุ่ม/หญ้าริมทาง และสีป่าที่หลากหลายขึ้น จัดวางเป็นกลุ่มสลับพื้นที่โล่ง พร้อมพื้นผิวใบไม้ที่สร้างในโค้ดและเงานุ่มจำลองรอบโคนต้น ปรับแสง hemisphere ให้แยกด้านสว่างและใต้พุ่ม ดูเป็นธรรมชาติขึ้นในแนว stylized ไม่ใช่ภาพถ่ายหรือการสำรวจพันธุ์ไม้จริง

ยังใช้ instancing ร่วมกับการตัดวัตถุไกลกล้อง ระดับต่ำใช้รูปทรงใบไม้ที่เบากว่าและความหนาแน่นตาม preset ตรวจภาพระดับต่ำ/สูงและกล้องตามรถ/คนขับในเบราว์เซอร์แล้ว ยังไม่ได้วัดประสิทธิภาพบนโทรศัพท์จริง นอกจากนี้แก้กรณีรับช่วงแข่งกลางทางแล้วคำนวณเวลา checkpoint ย้อนหลังจนติดลบ และไม่บันทึกรถเงาที่มีข้อมูลไม่ครบตั้งแต่ออกตัว

## รถสวนและอนิเมชันการขับล่าสุด

รถสวนเริ่มมาหลังออกตัว 5 วินาที แล้วเว้นประมาณ 14–18 วินาที โผล่ข้างหน้า 420 เมตรทางแนวขวา เซิร์ฟเวอร์ควบคุมตำแหน่งและตรวจการเคลื่อนผ่านกันในหนึ่ง tick หากชน รถแข่งและรถสวนหยุดที่ 0 โดยรถสวนจะค้าง 2 วินาทีแล้วจางหายเพื่อไม่ปิดการแข่งขันถาวร รถแข่งต้องเร่งใหม่ เมื่อกลับเข้าห้องจะรับรถสวนจาก snapshot ปัจจุบัน มีป้ายเตือนระยะรถสวนและบอทพิจารณารถสวนก่อนแซง

กล้องตามรถกดเมาส์ซ้ายค้างมองซ้าย ขวาค้างมองขวา ปล่อยแล้วกลับมองกลางถนน นอกเหนือจากโหมดภาพรวมที่ยังใช้คลิกขวาหมุนตามเดิม ล้อหน้าหันและค่อย ๆ กลับตามคำสั่งเลี้ยวพร้อมหมุนตามระยะรถ ตัวรถหมุน/เอียงอย่างนุ่มนวล เมื่อหลุดขอบจะพุ่งออกข้าง ตกลงด้วยความเร่งและพลิกก่อนหายไป แล้วเกิดใหม่ตามกติกาเดิมที่ความเร็ว 0

ลดช่องว่างจำลองใต้ถนนจากเดิมหลายเมตรเหลือประมาณ 0.6–0.7 เมตรตามข้อมูลพื้น และขยายไหล่ทางเป็นลาดเชื่อมกับภูมิประเทศ ระดับความสูง/ความชันของเส้นทางเดิมไม่ได้ถูกย่อสเกล

ตรวจรุ่นรถสวน: ชุดทดสอบปัจจุบัน 70 ข้อผ่าน รวมการจำลองรถ 8 คันต่างรุ่นจบ 39.9 กม. ทั้งแบบมีและไม่มีรถสวน พร้อมตรวจตัวถังรถแข่งและรถสวนทุก tick การตรวจในเบราว์เซอร์พบคำเตือนระยะรถสวนและรถสวนวิ่งย้อนทิศจริง ทดสอบปุ่ม D และการปล่อยคลิกขวาได้ Build ผ่าน การทดสอบบนโทรศัพท์จริงยังไม่ได้ทำ

## การแสดงรถและกล้องหมุนล่าสุด

แก้การแสดงตำแหน่งรถที่เคยถูกยุบเป็นจุดทุก 33ms ให้เรนเดอร์ระหว่าง snapshot ด้วย timestamp เซิร์ฟเวอร์ทุกเฟรม รถ กล้อง และรถสวนใช้ช่วงเวลาเดียวกัน ลดการแกว่งของ clock offset โดยคงการปรับทันทีกรณีคลาดเกินหนึ่งวินาที การชน/หลุดยังตัดสินบนเซิร์ฟเวอร์ตามเดิม

Third Person: คลิกซ้ายค้างแล้วลากเพื่อหมุนรอบรถและปรับมุมก้มเงย ปล่อยแล้วค้างมุมนั้น Scroll ซูมระยะ 4–24 เมตร คลิกขวาค้างเพื่อมองจากด้านหน้ารถย้อนทางไปด้านหลัง ปล่อยกลับมุมที่เลือกก่อนหน้า กดรถของฉันเพื่อกลับมองตามถนน โหมด First Person ยังลากหันแล้วคืนตรงเมื่อปล่อยเหมือนเดิม

วัสดุภูเขาใช้พื้นผิว procedural หญ้า ดิน หิน ผสมตามความชันและตำแหน่งโลก โดยฉายหินหลายแกนเพื่อลดการยืดบนหน้าผา ไม่มีการดาวน์โหลด texture ระหว่างเล่น และไม่ใช่ภาพถ่ายดาวเทียม

## มินิแมปและการเปิดเส้นทางร่วมกัน

ผู้นำเปิดเส้นทางล่วงหน้า 100 เมตร เซิร์ฟเวอร์เก็บระยะที่เปิดสะสมไว้ร่วมกันทั้งห้อง ผู้ตามเห็นเส้นทางที่เปิดแล้วเหมือนกัน เมื่อเปลี่ยนผู้นำหรือเชื่อมต่อกลับ พื้นที่เดิมยังคงเปิดอยู่ เริ่มแข่งใหม่จะรีเซ็ตระยะ ถนน ไหล่ทาง ป้าย และรายละเอียดข้างถนนที่ยังไม่เปิดจะถูกซ่อน ภูเขายังคงมองเห็นได้

ปุ่มแผนที่ใช้มินิแมปด้านบนแทนภาพรวมเดิม มินิแมปติดตามรถที่เลือก กดครึ่งจอหรือเต็มจอเพื่อขยาย ลากเพื่อเลื่อน Scroll หรือปุ่ม +/− เพื่อซูม กดจัดภาพเพื่อเห็นเส้นทางที่เปิดครบ และกดย่อเพื่อกลับมินิแมป แผนที่ทุกขนาดแสดงเฉพาะทางที่ผู้นำเปิดแล้ว การแข่งดำเนินต่อระหว่างเปิดแผนที่

ตรวจรุ่นนี้: Build ผ่านและชุดทดสอบปัจจุบัน 74 ข้อผ่าน รวมการเปิดเส้นทางโดยผู้นำ การคงพื้นที่เดิมหลังเปลี่ยนผู้นำ และการจำกัดระยะที่เส้นชัย ตรวจมินิแมป ครึ่งจอ และเต็มจอในเบราว์เซอร์เดสก์ท็อปแล้ว ยังไม่ได้ตรวจบนโทรศัพท์จริง

## รถ ห้องโดยสาร และการชนข้างทางรุ่นล่าสุด

- มินิแมปย้ายไปด้านขวาเหนือปุ่มกล้อง ขยายครึ่งจอ/เต็มจอยังจัดอยู่กลางจอ ระยะเปิดทางของผู้นำ 100 เมตรตาม config ใหม่
- ช่วง snapshot สำหรับรถ กล้อง กระจก และรถสวนเลือกใหม่ทุกเฟรม แก้การค้างที่ขอบช่วงเมื่อเดิมเปลี่ยน bracket ทุก 33ms การรับ snapshot ห้องเดิมระหว่างแข่งไม่ล้างบัฟเฟอร์ วัตถุข้างทางเก็บ matrix/สีล่วงหน้าและไม่สร้าง matrix ทั้งหมดใหม่ทุกครั้งที่เปิดทาง ยังคงบัฟเฟอร์ 200ms และหยุดคาดการณ์เมื่อข้อมูลขาด จึงไม่ได้รับรองว่าการเชื่อมต่อที่หลุดยาวจะไม่มีสะดุด
- เสากั้นข้างทางสนาม 1081 ใช้ตำแหน่งชุดเดียวกับตัวตรวจชนบนเซิร์ฟเวอร์ ตรวจตัวถังที่เคลื่อนผ่านเสาภายใน tick รถหยุด กระพริบ 1 วินาที แล้วเกิดที่ระยะเดิมในตำแหน่งปลอดภัยด้วยความเร็ว 0 ถ้ารถอื่นขวางทุกตำแหน่งจะรอจนปลอดภัยก่อนเกิด ยังคงอนิเมชันตกสำหรับการหลุดถนนในช่วงที่ไม่ชนเสา สามารถเลี้ยวออกถึงไหล่ทางได้
- หลังเกิดใหม่ กดเร่งช่วง 0–50 กม./ชม. จะใช้แรงเร่ง 1.6 เท่า จากนั้นกลับค่าปกติ (`respawnLaunchFactor`, `respawnLaunchUntilKmh`) รถสวนยังมีอยู่ แต่ไม่มีข้อความเตือนว่าจะถึงในกี่เมตร
- โมเดลรถทั้ง 10 รุ่นมีรูปทรงตัวถัง/ห้องโดยสารตามประเภทรถ ไฟ กระจังหน้า กระจก เสากระจก ล้อแม็กและยาง พร้อมกระบะท้ายหรือราวหลังคาตามรุ่น เพิ่มความยาวตัวถังและระยะกันชนเป็น 3.5 เมตรให้รองรับขนาดใหม่ เป็นโมเดล procedural ที่ประมาณรูปร่าง ไม่ใช่ CAD หรือสแกนรถผู้ผลิต และไม่มีโลโก้
- First Person เพิ่มห้องโดยสาร 3D พวงมาลัยขวาหมุนตามคำสั่งเลี้ยว กระจกหน้าและข้าง เสากระจก คอนโซล ช่องแอร์ เกียร์ และมาตรวัดความเร็วที่อัปเดตจากรถจริงในเกม หันศีรษะแล้วห้องโดยสารยังอยู่กับตัวรถ กระจกมองหลังกลางบนและกระจกข้างยังเรนเดอร์ภาพด้านหลังจริง ภายในเป็นแบบกลางใช้ร่วมกัน ยังไม่ได้ทำคอนโซลตรงรุ่นทั้ง 10 คัน
- ตรวจ Build และชุดทดสอบปัจจุบัน 80 ข้อผ่าน รวมทดสอบข้อมูลมาช้าไม่สม่ำเสมอ/ข้ามขอบ snapshot การชนเสาแบบกวาดตลอดช่วงเคลื่อนที่ เวลารอเกิดใหม่ การรอพื้นที่ว่าง และแรงเร่งหลังเกิดใหม่ ตรวจภาพในเบราว์เซอร์เดสก์ท็อปแล้ว ยังไม่ได้วัดประสิทธิภาพบนโทรศัพท์จริงหรือ Render รุ่นนี้

## โบนัสไล่ขบวนและเกาะท้าย

เซิร์ฟเวอร์คำนวณโบนัสอันดับละ 5% จากค่าสมรรถนะรถเดิม สูงสุด 20% เพิ่มทั้งอัตราเร่งและเพดานความเร็วเมื่อกดเร่งบนทางตรง โบนัสเต็มเมื่อห่างคันหน้าตามอันดับ 100 เมตรขึ้นไป ลดตามระยะและหมดที่ 40 เมตร เปลี่ยนระดับโบนัสอย่างค่อยเป็นค่อยไปภายในประมาณ 2 วินาที (`shared/chase.ts`) รถฐาน 180 กม./ชม. สามารถมีเพดานชั่วคราวสูงสุด 216 กม./ชม. โหมดนี้ใช้กับคนและบอทเหมือนกัน

เมื่ออยู่หลังคันหน้า 10–40 เมตรและแนวรถใกล้กัน เปลี่ยนเป็นเพิ่มอัตราเร่ง 15% จากการเกาะท้าย ออกแซงแล้วแรงส่งลดจนหมดใน 2 วินาที ไม่ซ้อนกับโบนัสอันดับ และแทนที่โบนัสเกาะท้ายเก่า ไม่เพิ่มความเร็วปลอดภัยหรือการเกาะถนน โบนัสปิดเมื่อเบรก/รักษาหรือถึงช่วงโค้ง ใช้การเบรกและโค้งสะอาดตามกติกาเดิม ไม่มีปุ่มย้ายกลับขบวน HUD แสดงชนิดและเปอร์เซ็นต์โบนัส ทดสอบเดิม 80 ข้อและทดสอบโบนัสเพิ่ม 3 ข้อผ่าน Build ผ่าน ยังไม่ได้ทดสอบสมดุลกับผู้เล่นจริงบน Render

## เพดาน 150 และการออกตัวหลังหยุด

ลดฐานความเร็วสูงสุดจาก 180 เป็น 150 กม./ชม. รถแต่ละรุ่นยังมีตัวคูณสมรรถนะเดิม โบนัสไล่ตามอันดับละ 5% สูงสุด 20% ยังคงเพิ่มทั้งอัตราเร่งและเพดานตามเงื่อนไขระยะเดิม รถฐาน 150 จึงมีเพดานชั่วคราว 157.5 / 165 / 172.5 / 180 กม./ชม. ตามระดับโบนัส การเบรกและการเกาะโค้งไม่เพิ่มตามอันดับ

เมื่อรถหยุดจนความเร็วเป็น 0 ทุกสาเหตุ เช่น เบรก ชน หรือเกิดใหม่ จะเปิดแรงเร่งออกตัว 2 เท่าจนถึง 60 กม./ชม. ต้องกดเร่งเอง เมื่อถึง 60 จะกลับแรงเร่งปกติ ไม่เร่งให้อัตโนมัติขณะหยุด การช่วยไล่ตามยังใช้ร่วมกับแรงออกตัวตามเงื่อนไขเดิมได้ ค่าปรับอยู่ที่ respawnLaunchFactor และ respawnLaunchUntilKmh ใน CONFIG

## โหมดภาพสบายตา

เปิดเป็นค่าเริ่มต้นในเมนูภาพ: FOV คงที่ตามค่าผู้เล่นเลือก (แนวนอน 70–110 องศา จำกัดมุมแนวตั้งในจอแคบ), กล้องตามรถเริ่ม 12 เมตร ปรับ 8–20 เมตร, ไม่ใช้เอฟเฟกต์เส้นความเร็ว และกระจกทั้งสามบานเริ่มปิด ผู้เล่นเลือกเปิดกระจกเองได้หรือปิดโหมดสบายตาเพื่อใช้กล้องเดิม การตั้งค่าจำใน localStorage แยกแต่ละเครื่อง

Third Person โหมดนี้ติดตำแหน่งรถตรง ๆ เพื่อไม่หน่วงตามหลังรถ ใช้ทิศทางที่จำกัดการหมุนและรักษาแกนตั้งของกล้อง First Person กรองมุมก้มเงยให้ใกล้เส้นขอบฟ้าและหมุนตามโค้งอย่างค่อยเป็นค่อยไป ห้องโดยสารยังอยู่กับรถ การหมุนเมาส์เป็นการควบคุมของผู้เล่นตามเดิม ไม่มีการเปลี่ยนความเร็วรถหรือผลบนเซิร์ฟเวอร์ เพิ่ม P95 ของช่วงเวลา requestAnimationFrame และจำนวนเฟรมเกิน 33.4ms ในเมนูภาพเพื่อช่วยดูอาการสะดุด (ไม่ใช่การวัด GPU โดยตรง)

ตรวจกล้องและเมนูในเบราว์เซอร์เดสก์ท็อปแล้ว ยังต้องให้ผู้เล่นเดิมทดสอบว่าลดอาการได้จริงเพียงใด และยังไม่ได้ตรวจบนมือถือจริง การเปลี่ยนนี้ไม่ได้รับรองว่าจะไม่มีอาการสำหรับทุกคน

## ถนนกว้าง เบรกแตะ และชนท้ายแบบใหม่

- ถนนกว้าง 9.45 เมตร (เพิ่ม 50% จาก 6.3) ตำแหน่งรถ กล้อง รถสวน รถเงา และตัวตรวจชนใช้ระยะด้านข้าง 2.94 เมตรต่อหน่วยเดียวกัน ปรับความกว้าง corridor ให้ขนาดตัวถังทางกายภาพคงเดิม เสากั้น/ราวอยู่ห่างจากขอบถนน 0.65 เมตร ป้ายกิโลเมตรย้ายออกไป 6.2 เมตรจากกลางถนน
- ยกเลิกการเปิดทางของผู้นำ ถนนและแผนที่เปิดทั้งสนามตั้งแต่เริ่ม รถไม่ถูกซ่อนเพราะระยะมองเห็น หมอกย้ายออกไปไกลกว่าขนาดสนาม รายละเอียดต้นไม้ยังใช้ LOD ตามคุณภาพเพื่อลดภาระเครื่อง ภูเขายังบังถนนตามรูปทรงจริงได้
- เบรกแตะลดความเร็วสะสม 5% หนึ่งครั้ง การกดค้างเกิน 250ms จะเริ่มเบรกต่อเนื่องและเพิ่มแรงตามเวลาค้าง สูงสุด 2 เท่าของแรงเบรกปกติ ค่ารถมีผลกับแรงเบรกค้าง ปุ่มหน้าจอปล่อยแล้วรักษาเช่นเดียวกับ S และมือถือ เซิร์ฟเวอร์จำจังหวะแตะแม้กดแล้วปล่อยก่อน tick ถัดไป ไม่รับค่าความเร็วจากไคลเอนต์
- ชนท้ายครั้งแรกหักความเร็วสะสม 50% เฉพาะคันหลัง ไม่หยุดบังคับหรือหักซ้ำทุก tick ถ้าคันหน้ายังขวาง ความเร็วการเดินทางจริงอาจต่ำกว่าครึ่งเพื่อไม่ให้รถซ้อนกัน ต้องแซงหรือรอช่องว่าง รถสวนและเสายังใช้บทลงโทษเดิม
- รถทั้ง 10 คันมี handling ต่างกันและใช้ค่านั้นคำนวณความเร็วปลอดภัยในโค้งจริง รวมกับอัตราเร่ง เบรก และความเร็วปลายเดิม แสดงในหลอดสมรรถนะ เปลี่ยนรุ่นบันทึกรถเงาเป็น v3 เพื่อไม่เทียบเวลาภายใต้กติกาเดิมกับกติกาใหม่
- ชุดทดสอบ 92 ข้อผ่าน รวมเบรกแตะ 5% / กดค้าง / แตะระหว่าง tick การหักครึ่งเมื่อชนท้ายครั้งเดียว ความกว้างถนนและระยะชนจริง และรถ 8 คันจบสนาม 39.9 กม. แบบมี/ไม่มีรถสวน

## บอทเลือกแซงและแก้แผนที่เต็มจอ

บอทประเมินช่องซ้าย/ขวา ความเร็วรถด้านหน้า รถที่กำลังไล่มาจากข้างหลัง และรถสวน เลือกช่องที่มีระยะวิ่งโล่งและความเร็วขบวนดีกว่า คงเป้าหมายช่วงหนึ่งเพื่อลดการโยกกลับไปมา ระดับง่ายเริ่มหาแซงประมาณ 45 เมตร ตอบสนอง 0.9 วินาทีและเว้นการวางแผนใหม่ 2.6 วินาที ระดับกลาง 85 เมตร / 0.3 วินาที / 1.4 วินาที ระดับยาก 140 เมตร / วางแผนทันทีเมื่อรอบคิดบอทมาถึง / 0.8 วินาที ประเมินความเร็วสัมพัทธ์ล่วงหน้าต่างกัน เซิร์ฟเวอร์ยังคิดคำสั่งบอทตาม botThinkMs และใช้กติกาชน/เลี้ยวเดียวกับผู้เล่น

แก้การลากแผนที่: เดิม functional state updater อ่าน e.currentTarget หลัง callback อีเวนต์จบแล้ว ทำให้เป็น null ได้ เปลี่ยนเป็นอ่านพิกัดและขนาดก่อนอัปเดต state เก็บ pointerId และตำแหน่งล่าสุด มีการยกเลิกการลากเมื่อปล่อย/เสีย pointer capture และป้องกันตัวหารศูนย์ ตรวจคลิก ลาก ซูม และย่อแผนที่เต็มจอในเบราว์เซอร์เดสก์ท็อปแล้ว หน้าเกมยังทำงานต่อ การสัมผัสบนโทรศัพท์จริงยังไม่ได้ตรวจ

## สไลด์ควบคุมมือถือ

เปลี่ยนปุ่มมือถือเป็นสไลด์เลี้ยวแนวนอนและสไลด์คันเร่ง/เบรกแนวตั้ง ใช้งานสองนิ้วพร้อมกันได้ แต่ละแกนปล่อยแล้วคืนกลางโดยไม่ยกเลิกอีกแกน มี deadzone 3% และรีเซ็ตเมื่อแอปเสียโฟกัส เซิร์ฟเวอร์ตรวจ steering -1..1 และ power 0..1 แล้วคำนวณอัตราเร่ง/แรงเบรกตามแรงสไลด์ การแตะเบรกยังคงหัก 5% ตามกติกา ส่วนแรงเบรกค้างปรับได้ตามระยะสไลด์ ทดสอบตรรกะการควบคุมและสัดส่วนแรงแล้ว ยังไม่ได้ตรวจการสัมผัสบนโทรศัพท์จริง

## โหมดผู้ชมและหน้าจอมือถือ

หน้าแรกเลือกเข้าห้องเป็นผู้ชมได้ หรือกดเปลี่ยนบทบาทในล็อบบี้ เจ้าของห้องที่เป็นผู้ชมยังเพิ่ม/ลบบอทและเริ่มการแข่งขันได้ สนามรับนักแข่ง 8 คันโดยไม่นับผู้ชม เซิร์ฟเวอร์ตรวจจำนวนรถและปฏิเสธคำสั่งขับจากผู้ชม การกลับเข้าด้วย token คงบทบาทเดิม และผู้ชมที่เชื่อมต่ออยู่ยังอยู่ในห้องหลังแก้มือ

ระหว่างแข่ง ช่องเลือกรถที่ติดตามใช้เลือกบอทหรือเพื่อนได้ทั้งมุมตามรถและในรถ เสียงใช้รถที่ติดตาม ผู้ชมไม่มีปุ่มขับหรือ HUD ความเร็วของตัวเอง เมื่อผู้เล่นเปลี่ยนไปดูรถอื่นจะพักการควบคุมรถตัวเองเป็นรักษา/เลี้ยวตรง และมีปุ่มรถคุณเพื่อกลับมาขับ

มือถือย่อสไลด์ให้โปร่งขึ้น ลดขนาดแผงคันเร่ง/เบรกและเว้นพื้นที่ด้านล่างจากปุ่มภาพ มินิแมปเริ่มซ่อนในมือถือ เปิดด้วยปุ่มแมป ปิดด้วยซ่อนแมปหรือ × จำการเลือกในเครื่อง เมื่อแสดงมีขนาดเล็กชิดมุมบนขวา ขยาย 2×/เต็มจอยังใช้ได้ ตรวจหน้าจอจำลอง 390×844 แล้ว ยังไม่ได้ทดสอบการสัมผัสสองนิ้วบนโทรศัพท์จริง

Build และชุดกติกา 101 ข้อผ่าน เพิ่ม `npm run test:online` สำหรับทดสอบ Socket.IO ที่ localhost:3042 (เปิด npm run dev ก่อน) ครอบคลุมเจ้าของห้องเป็นผู้ชม บอทครบ 8 คัน ปฏิเสธเปลี่ยนเป็นนักแข่งเมื่อเต็ม เริ่มแข่งแบบบอทล้วน ปฏิเสธคำสั่งขับของผู้ชม และ reconnect การทดสอบสร้างห้องชั่วคราวบนเซิร์ฟเวอร์ local

- ก่อนออกตัว เซิร์ฟเวอร์นับถอยหลัง 5 วินาที ระหว่างนั้นรถยังไม่เคลื่อนและปฏิเสธคำสั่งขับ

### ห้องและ Render

หน้าแรกแสดงทุกห้องที่ยังอยู่บนเซิร์ฟเวอร์ รวมถึงห้องบอท และรีเฟรชทุก 10 วินาที ถ้าไม่มีมนุษย์เชื่อมต่อทั้งนักแข่งและผู้ชม การจำลองจะพักทันที ห้องจะถูกลบหลังว่าง 10 นาที โดยตรวจทุก 30 วินาที ผู้เล่นกลับเข้าก่อนหมดเวลายังใช้ session token เดิมได้

แคชข้อมูลสนามที่ตรวจผ่านแล้วแยกตามระยะ ใช้ volatile สำหรับข้อมูลตำแหน่งถี่ ๆ เพื่อไม่สะสมแพ็กเก็ตเก่า ตัดความจำบอทออกจาก payload แยก Three.js vendor สำหรับแคชข้ามรุ่น และตั้ง immutable cache กับไฟล์ assets ที่มีชื่อ hash ส่วน snapshot/reconnect ยังส่งแบบ reliable การปิดห้องลดงานจำลองและหน่วยความจำ แต่ไม่ได้ปิด Web Service ของ Render เอง และยังไม่ได้วัดปริมาณโควต้าที่ประหยัดได้

## โบนัสไล่ตามสองเท่าและเกิดใหม่จากรถสวน

โบนัสอันดับ 1–8 ล่าสุดคือ 0/10/20/30/40/40/40/40% (แทนชุดเดิม) รถฐาน 120 มีเพดาน 120/132/144/156/168/168/168/168 กม./ชม. เงื่อนไขทางตรง ระยะห่าง และเกาะท้าย 15% ยังเหมือนเดิม

เมื่อชนรถสวน รถผู้เล่นกลับฝั่งซ้ายที่ความเร็ว 0 ทันที เลือกตำแหน่งที่เว้นรถคันอื่น มีอมตะ 3 วินาทีที่เซิร์ฟเวอร์คุม ป้องกันรถสวน เสา และการหลุดซ้ำ พร้อมตัวรถเรืองแสงเป็นจังหวะโดยไม่ซ่อน รถสวนยังขับต่อ ส่วนการชนท้ายผู้แข่งขันยังใช้กติกาเว้นระยะเดิม

เส้นประเหลือกลางถนนเท่านั้น ใช้แผ่นผิวตามจุดแบ่งสามเหลี่ยมเดียวกับถนน ลดการลอยและใช้ polygon offset ป้องกันภาพกะพริบ เสาข้างทางเปลี่ยนเป็นหลักเล็กขาวคาดดำ ไม่มีราวแนวนอน เสียงยางเข้าโค้งลดระดับและความถี่พร้อมกรองเสียงแหลม
