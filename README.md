# เส้นทางเล็ก มหาขุนเขา — ต้นแบบเรียลไทม์

เกมแข่งรถล้อเปิดบนภูเขาสำหรับ 2–8 คน เซิร์ฟเวอร์เป็นผู้ตัดสินความเร็ว ตำแหน่ง การเปลี่ยนเลน อุบัติเหตุ และผู้ชนะ ข้อมูลห้องอยู่ในหน่วยความจำ

## เริ่มเล่น

ต้องมี Node.js 20.19+ หรือ 22.12+ (ทดสอบด้วย Node 24)

```sh
npm install
npm run dev
```

เปิด http://localhost:5173 สร้างห้อง แล้วชวนเพื่อนด้วยรหัสห้อง หรือกด **เพิ่มบอท** เพื่อทดลองคนเดียว ผู้เล่นทุกคนกดพร้อมก่อนเจ้าของห้องกดเริ่ม แข่งได้ 2–8 คันรวมบอท การเชื่อมต่อจากเครื่องอื่นต้องเข้าถึง URL เครือข่ายที่ Vite แสดงได้ หยุดเซิร์ฟเวอร์ด้วย Ctrl+C; ห้องจะหายเมื่อเซิร์ฟเวอร์หยุด

```sh
npm run build
npm test
```

## วิธีเล่น

- สนามยาว 2,000 เมตร จากตีนเขาขึ้นบริเวณยอดและลงอีกฝั่ง สุ่มจาก seed มีโค้งกว้าง โค้งแคบ โค้งยาว และทางตรงยาว
- แตะ **เร่ง / รักษา / เบรก** ได้ทันที คำสั่งมีผลต่อเนื่องจนแตะปุ่มอื่น ไม่มีช่วงนับถอยหลัง ความเร็วบนหน้าจอเป็นกิโลเมตรต่อชั่วโมง
- เลือกเลนซ้ายหรือขวาได้ รถค่อย ๆ ย้ายเลนเมื่อช่องว่างปลอดภัย หลายคันใช้เลนเดียวกันได้หากมีระยะห่างพอ รถที่ติดคันหน้าจะชะลอ
- ความเร็วเกินในโค้งทำให้เสียความเร็ว การฝืนรุนแรงที่โค้งหน้าผามีโอกาสเสียชีวิตเฉพาะเมื่อผู้เล่นกดยืนยันโค้งนั้น ถ้าไม่ยืนยันระบบชะลอให้ปลอดภัย ไม่มีแต้มสภาพรถ
- บอทเลือกคำสั่งและเลนโดยเซิร์ฟเวอร์ และไม่ยืนยันความเสี่ยงเสียชีวิต กล้องคนขับจำกัดมุมแนวนอนไม่เกิน 90 องศา ระยะมองเห็นประมาณจากถนนและภูมิประเทศขณะเคลื่อนที่
- หากหลุด ระบบคงความเร็วและยกเลิกการยืนยันความเสี่ยง สามารถกลับเข้าด้วย session token ของเบราว์เซอร์ และผู้เข้าหลังเริ่มเป็นผู้ชม

## ข้อจำกัดของต้นแบบ

- สนามสร้างจากแพตเทิร์นโค้งที่มีการสุ่มรายละเอียด เส้นทางกติกาและถนน 3D ใช้เส้นทางเดียวกัน แต่ยังไม่ใช่ generator ภูเขาทุกชนิด ตัวตรวจสนามยังไม่ครอบคลุมทุกเงื่อนไข
- ฉากและรถเป็น low-poly สเกลภาพยังเป็นภาพแทนเพื่อให้เห็นรถง่าย ไม่ใช่แบบจำลองรถและภูมิประเทศที่มีสัดส่วนทางกายภาพแม่นยำ
- บอทใช้กฎง่าย ๆ ไม่ใช่ AI ที่ปรับระดับความสามารถ ระบบมองเห็นประมาณจากแนวถนนและพื้นผิวภูเขา ยังไม่ได้จำลองการบังสายตาของทุกวัตถุ
- ยังไม่มีฐานข้อมูล บัญชี โฮสติ้งสาธารณะ สถิติสมดุล หรือการทดสอบมือถือและเครือข่ายจริงอย่างครบถ้วน เวลาแข่งยังต้องวัดจากผู้เล่นจริง
- ยังควรตรวจความปลอดภัยของเซิร์ฟเวอร์และการจำกัดทรัพยากรก่อนเปิดเป็นบริการสาธารณะ

## Deploy บน Render

สร้าง Web Service จาก GitHub repository ของโปรเจกต์ โดยใช้ Node.js 22 หรือใหม่กว่า ตั้ง Build Command เป็น `npm ci --include=dev && npm run build` และ Start Command เป็น `npm start` เซิร์ฟเวอร์อ่านพอร์ตจาก `PORT` และให้บริการหน้าเว็บกับ Socket.IO ผ่านพอร์ตเดียวกัน ใช้หนึ่ง instance เพราะห้องอยู่ในหน่วยความจำและจะหายเมื่อ instance รีสตาร์ตหรือ deploy ใหม่
